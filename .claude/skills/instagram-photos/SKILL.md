# 인스타그램용 사진 뽑기

사용자는 초등학생 수준의 초보자다. 어려운 용어 없이 짧게 말한다.
인스타그램에 직접 올리지는 않는다(로그인 계정 작업, 사용자가 직접 올린다).
GitHub에 올리지 않는다. 결과 사진은 내 컴퓨터 폴더에만 저장된다.

## 순서

1. **파일 찾기** — 사용자가 준 경로/이름이 정확하지 않으면 `D:\claude\portpolio\storyboard\`, `stories\` 아래에서 찾는다.
   여러 개가 맞으면 목록을 보여 주고 하나만 묻는다.
2. **사진 뽑기**:
   ```bash
   PYTHONIOENCODING=utf-8 python -I "D:/claude/portpolio/.claude/skills/instagram-photos/extract.py" "경로" [최대장수]
   ```
   - 기본은 최대 20장(인스타 한 게시물 한도). 사용자가 "10장만" 하면 10을 붙인다.
   - 결과는 `D:\claude\instagram-photos\<책 이름>\01.jpg, 02.jpg ...` (1080×1080, 가운데 기준으로 잘림).
   - 출력이 `!`로 시작하면 실패: 그림이 없는 이야기책이면 "이 책에는 그림이 없어서 사진을 만들 수 없어요"라고 쉽게 말한다.
3. **확인** — 첫 장과 마지막 장 중 한두 장을 Read로 열어 보고 그림이 이상하게 잘리지 않았는지 본다.
   (가운데만 남기고 위아래·양옆을 자르므로 글자나 중요한 부분이 잘렸는지 확인)
4. **폴더 열어 주기** — `mcp__ccd_host__reveal_path`(도구가 있으면)로 폴더를 보여 주거나, 폴더 경로를 코드 블록으로 알려 준다.
5. **결과 알려 주기** — 짧게:
   - 사진 몇 장을 만들었는지, 저장 폴더
   - 인스타에서 할 일(아래 안내를 그대로, 쉬운 말로)

## 인스타그램에 올리는 법 (사용자에게 알려 줄 내용)

- 휴대폰으로 올리려면 먼저 사진을 폰으로 옮긴다(카카오톡 "나와의 채팅"에 보내거나 USB·구글 포토 등).
- 인스타 앱 → 아래 가운데 **+** → **게시물** → 사진 여러 장 선택(오른쪽 아래 겹친 네모 버튼) → 순서대로 고르기 → **다음** → 글 쓰기 → **공유**
- 컴퓨터(instagram.com)에서도 왼쪽 메뉴 **만들기**에서 올릴 수 있다.
- 글 끝에 "전체 보기는 프로필 링크에서!"라고 쓰고, 프로필에 책 주소(페이스북 공유 때 쓴 주소)를 넣으면 좋다. 게시물 글 안의 링크는 눌러도 열리지 않는다.

## 주의

- 인스타는 한 게시물에 최대 20장이다. 책 그림이 더 많으면 앞에서 끝까지 고르게 20장을 뽑는다. 전부 필요하면 게시물을 나눠 올린다고 안내한다.
- 사진은 쓰는 사람이 받은 그림 그대로 자른 것이다. 원본(책 파일)은 바뀌지 않는다.
- 같은 책을 다시 뽑으면 기존 사진을 지우고 새로 만든다.
